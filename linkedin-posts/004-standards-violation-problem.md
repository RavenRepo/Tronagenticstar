## The Post:

We watched top tools break 3 unwritten rules of good software.

AI tools that violate best practices while claiming to help.

Last month, I audited code generated by popular AI assistants across 5 enterprise teams.

**The results were eye-opening:**

**Rule #1 Broken: "Follow established patterns"**
- Copilot suggested REST endpoints that ignored our API versioning conventions
- Generated database queries that bypassed our connection pooling layer
- Created React components that violated our design system standards

**Rule #2 Broken: "Respect internal libraries"**
- AI recommended reinventing utilities we'd already built and tested
- Suggested external dependencies for problems our internal libs solved
- Generated code that duplicated functionality from our core framework

**Rule #3 Broken: "Maintain architectural consistency"**
- Created microservices that ignored our service mesh patterns
- Suggested authentication flows that bypassed our SSO standards
- Generated async code that didn't follow our error handling conventions

**The pattern was clear:**

These tools treat your codebase like a generic programming exercise, not a sophisticated system with years of architectural decisions.

**Real example from a fintech client:**
